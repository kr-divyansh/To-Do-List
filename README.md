# Todo List App 📝

A simple and interactive Todo List application that helps users organize their daily tasks, manage their work, and keep track of completed activities.

## 🚀 Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 📋 View and manage daily tasks
- 🎨 Simple and user-friendly interface
- 📱 Clean and responsive design

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 📂 Project Structure

```text
Todo-List/
├── index.html
├── style.css
├── script.js
└── README.md
```

## ⚙️ How to Run

1. Clone this repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start adding and managing your tasks!
